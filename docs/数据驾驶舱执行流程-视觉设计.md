# 精密分层

这套视觉语言以清晰的系统边界为核心。空间被组织成连续但彼此独立的阶段，每个阶段拥有稳定的留白、明确的进入点和唯一的退出方向。形状不是装饰，而是职责边界；连线不是轨迹，而是数据和控制权的交接。整体应呈现经过反复校准的秩序感。

色彩承担语义。蓝色描述正常处理，绿色确认成功和可用结果，红色隔离失败路径，紫色标记独立持久化边界。灰色仅用于辅助关系和不参与区域。所有颜色保持克制、低噪声，并通过精确对比保证信息在投屏和缩放场景下仍然清晰。

尺度用于表达重要性。阶段标题形成稳定节奏，业务节点保持一致尺寸，事务边界和最终展示获得更大的视觉重量。文字只保留完成判断所需的短句，信息优先通过位置、颜色、分组和方向传达。每个间距都应像经过无数次推敲一样准确。

构图强调从左到右的单向主叙事，同时将失败路径向下分离，使成功和失败无需阅读说明即可辨认。跨表逻辑关联使用轻量虚线，避免与主处理路径争夺注意力。最终成果应具有主编级信息设计的严谨度，细节经得起近距离检查。

制作必须体现熟练工匠的耐心：圆角、线宽、箭头、字体基线和色块明度均需统一。任何文字不得贴边或重叠，任何连线不得穿过节点。成品应像由顶尖信息设计师耗费大量时间完成，精准、安静且不留偶然。
