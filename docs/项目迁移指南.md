# 项目迁移指南

本文用于将自动通报项目迁移到另一台 Windows 电脑，或迁回原电脑。

## 一、迁移前准备

建议复制以下内容：

- 项目源代码
- `config/reports/` 正式通报配置
- `config/modules/` 模块配置
- `templates/` 通报模板
- `frp/frpc.toml` 公网映射配置
- `scripts/prefect_env_prod.local.ps1` 正式数据库连接配置

不建议直接复制以下运行时文件：

- `runtime/prefect_home/prefect.db`
- `runtime/locks/`
- `runtime/browser_session/`
- `runtime/flow/`
- `runtime/drafts/`

Cookie 和浏览器会话通常与电脑环境有关。迁移后应重新登录，不要依赖旧电脑的
`runtime/cookies/` 和浏览器 Profile。

## 二、新电脑需要安装的软件

- Conda（Miniconda 或 Anaconda）
- Python 3.11
- Node.js 和 npm
- Microsoft Edge
- Microsoft Excel
- PowerShell 7（`pwsh`）

项目当前固定使用：

```text
Python 3.11
Prefect 3.7.0
Conda 环境名 auto-notify
```

Prefect 版本不要随意降低。正式 PostgreSQL 的 Alembic revision
`7218aad17905` 来自 Prefect 3.7.0，使用 Prefect 3.6.x 会导致服务启动失败。

## 三、初始化环境

进入项目根目录执行：

```powershell
pwsh -File scripts\setup_windows_env.ps1
```

该脚本会：

- 创建或复用 `auto-notify` Conda 环境
- 安装 `requirements.txt`
- 创建必要的 `runtime/` 目录
- 检查 Edge 和 Excel COM
- 将 `config/modules/autologin.json` 的 Python 路径更新为当前电脑路径
- 执行基础模块导入测试

已有 Conda 环境时：

```powershell
pwsh -File scripts\setup_windows_env.ps1 -SkipCondaCreate
```

## 四、迁移后必须检查的文件

### 1. 自动登录 Python 路径

文件：

```text
config/modules/autologin.json
```

检查 `login_command` 是否指向当前电脑真实存在的解释器，例如：

```text
C:\Users\用户名\.conda\envs\auto-notify\python.exe
```

通常不需要手工修改，`setup_windows_env.ps1` 会自动写入。

### 2. 正式 Prefect 数据库

文件：

```text
scripts/prefect_env_prod.local.ps1
```

格式：

```powershell
$env:AUTO_NOTIFY_PREFECT_DATABASE_URL = "postgresql+asyncpg://用户名:密码@服务器:5432/prefect"
```

这是本机敏感配置。确认数据库地址、账号、密码和网络访问均有效。

### 3. 通报模板路径

文件：

```text
config/reports/*.json
```

检查每份配置的：

```json
"template_path": "templates/示例.xlsx"
```

应优先使用项目相对路径，不要写旧电脑的绝对路径。

### 4. 企业微信发送配置

文件：

```text
config/reports/*.json
config/modules/wecom_sender.json
```

检查 Webhook、发送项、工作表名称和输出内容。真实试跑会真实发送消息。

### 5. FRP 公网映射

文件：

```text
frp/frpc.toml
```

检查：

- `serverAddr`
- `serverPort`
- `auth.token`
- `localPort`
- `remotePort`

`frpc.exe` 不建议从来源不明的位置复制。应从
[FRP 官方 GitHub Release](https://github.com/fatedier/frp/releases) 下载 Windows amd64
版本，并核对 Release 页面给出的 SHA-256。

Windows Defender 可能将 `frpc.exe` 识别为潜在垃圾软件并隔离。项目脚本不会自动关闭
Defender，也不会自动添加安全排除项。

暂时不需要公网映射时：

```powershell
pwsh -File scripts\public_stack.ps1 -Action start -SkipFrp
```

## 五、通常不需要手工修改的脚本

以下脚本已经改为自动查找名为 `auto-notify` 的 Conda 环境：

- `scripts/prefect_start.ps1`
- `scripts/admin_react_start.ps1`
- `scripts/simulate_clean_concurrent_login.ps1`
- `scripts/prefect_stop.ps1`

脚本同时设置 `PYTHONNOUSERSITE=1`，避免混入系统 Python 或用户目录中的其他 Python 包。

迁移后不应再把脚本改成固定的 `C:\anaconda3\python.exe`。

## 六、启动方式

本地调试，不连接正式 PostgreSQL，也不启用公网映射：

```powershell
pwsh -File scripts\public_stack.ps1 -Action start -UseSqliteDebug -SkipFrp
```

正式 PostgreSQL，不启用公网映射：

```powershell
pwsh -File scripts\public_stack.ps1 -Action start -SkipFrp
```

正式运行并启用 FRP：

```powershell
pwsh -File scripts\public_stack.ps1 -Action start
```

停止服务：

```powershell
pwsh -File scripts\public_stack.ps1 -Action stop
```

## 七、迁移后验证

### 1. 检查 Python 和 Prefect

```powershell
C:\Users\用户名\.conda\envs\auto-notify\python.exe -c "import sys, prefect; print(sys.executable); print(prefect.__version__)"
```

预期 Prefect 版本：

```text
3.7.0
```

### 2. 运行测试

```powershell
C:\Users\用户名\.conda\envs\auto-notify\python.exe -m pytest -q
```

### 3. 检查服务

```text
Prefect: http://127.0.0.1:4200/api/health
后端:    http://127.0.0.1:8000/api/health
前端:    http://127.0.0.1:5173
```

### 4. 先做安全测试

在 React 配置中心执行“安全测试”。该模式不会真实下载、不会发送企业微信，也不会提交模板。

确认安全测试通过后，再根据需要进行真实试跑。真实试跑会下载业务数据并发送企业微信。

## 八、常见迁移错误

### 使用了错误的 Python

现象：

```text
C:\anaconda3\python.exe
```

或 Prefect 从以下目录加载：

```text
AppData\Roaming\Python\Python313\site-packages
```

处理：

- 使用 `auto-notify` Conda 环境
- 使用项目启动脚本
- 不要直接执行系统 `python`

### Prefect 找不到 Alembic revision

现象：

```text
Can't locate revision identified by '7218aad17905'
```

处理：

- 确认安装 `prefect==3.7.0`
- 不要用 Prefect 3.6.x 连接已经由 3.7.0 升级的正式数据库

本地 SQLite 出现类似错误时，先停止 Prefect，备份
`runtime/prefect_home/prefect.db`，再让 Prefect 创建新库。不要直接删除正式 PostgreSQL 数据。

### frpc 被 Defender 隔离

现象：

```text
无法成功完成操作，因为文件包含病毒或潜在的垃圾软件
```

处理：

- 只从 FRP 官方 Release 下载
- 核对 SHA-256
- 在 Windows 安全中心查看“保护历史记录”
- 不需要公网时使用 `-SkipFrp`
- 不要关闭整个 Defender
