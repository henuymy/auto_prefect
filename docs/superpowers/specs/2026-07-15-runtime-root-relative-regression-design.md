# 运行根相对路径回归验证

## 目标

防止已迁移到共享运行根目录的配置、API、Flow 和前端展示重新输出或接受
`runtime/...` 前缀。业务代码继续使用受控的根相对路径，例如
`session/...`、`flow/<任务>/output/...`。

## 范围

- 路径服务：验证根相对路径可解析到共享运行根，并拒绝绝对路径、父目录路径
  和 `runtime/...` 前缀。
- 配置与 API：验证保存、读取和运行目录响应均返回根相对路径。
- Flow：验证任务配置覆盖写入的运行目录字段为根相对路径，解析目标仍位于共享
  运行根内。
- 前端：验证运行目录抽屉在根目录显示 `.`，子路径按 API 返回值展示，不再拼接
  `runtime/`。

## 非目标

- 不执行登录、下载、浏览器控制、消息发送或 Prefect 部署。
- 不变更认证材料、生产运行根或历史路径迁移策略。
- 不移除用于拒绝旧路径的内部兼容校验和历史故障说明。

## 验收

相关 pytest 用例覆盖上述后端与 Flow 契约并通过。前端依赖可用时，TypeScript
类型检查通过；依赖缺失时记录该限制，不安装或修改依赖锁文件。
