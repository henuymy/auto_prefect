# 登录命令失败诊断

## 目标

自动登录命令失败时，在 Prefect 的异常链中显示可操作的失败原因，同时不暴露认证信息。

## 设计

`run_login_command` 已经捕获子进程标准输出和标准错误。子进程返回非零退出码时，现有的
`RuntimeError` 将由以下内容构成：

- 退出码；
- 一条简短、规范化的诊断摘要：优先取标准错误；标准错误为空时取标准输出。

不会记录登录命令本身。诊断摘要复用现有登录失败的脱敏策略：包含敏感字段名的摘要会替换为
脱敏标记，且长度受现有最大摘要长度限制。这样既能显示“等待 Gotify 验证码超时”等常见原因，
也维持现有的密钥安全边界。

## 测试

新增针对非零退出码的测试，验证普通的验证码超时诊断会被保留、包含敏感内容的子进程诊断会被
脱敏。现有测试继续确保在没有安全诊断可用时，原始输出和登录命令都不会出现在异常中。
