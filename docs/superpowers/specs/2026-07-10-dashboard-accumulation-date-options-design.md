# 驾驶舱日累计日期懒加载设计

## 目标

使“累计”模式的日期选择与历史档位一致：只展示实际存在日累计数据的日期，并支持长保留期下的按页懒加载。

## 接口

新增 `GET /api/dashboard/acc/options`，参数为 `page`（默认 1）和 `page_size`（默认、最大 50）。接口只查询 `MetricAccV2` 中 `period_type = DAY_ACC` 的不同 `stat_date`，按日期倒序返回：

```json
{"dates":["2026-07-08"],"page":1,"page_size":50,"total":123,"has_more":true}
```

## 前端交互

累计模式首次进入时读取第 1 页，默认选第一项（最新可用日期）。日期控件改为下拉列表；用户滚动到列表底部时请求下一页并追加选项，直到 `has_more` 为 `false`。用户选择日期并点击查询后，继续调用已有日累计查询接口。

## 约束与错误处理

- 只返回实际有 `DAY_ACC` 数据的日期，不允许手工输入任意日期。
- 接口或加载下一页失败时，保留已加载选项和当前选中日期；页面沿用现有请求错误提示。
- 不改变历史档位、实时或实时累计的时间选择和数据口径。

## 验证

- 后端测试覆盖日期去重、倒序、分页和 `DAY_ACC` 过滤。
- 路由测试覆盖默认/边界分页参数及响应转发。
- 前端契约测试覆盖累计选项接口、下拉控件与加载更多的状态/回调。
