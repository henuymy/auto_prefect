# 启动与环境

项目根目录：

```text
C:\Users\yuyu\Desktop\项目\自动通报
```

开发环境完整启动：

```powershell
pwsh -File scripts\dev\start.ps1 -ForceRestart
```

如需同时清理历史待执行任务：

```powershell
pwsh -File scripts\dev\start.ps1 -ForceRestart -ClearScheduledBacklog
```

服务地址：

- Prefect UI：`http://127.0.0.1:4200`
- 后端：`http://127.0.0.1:8000/api/health`
- 前端：`http://127.0.0.1:5173`

开发环境使用 `prefect_dev` 数据库，Dashboard MySQL 配置由
`scripts/dashboard/mysql_env.local.ps1` 提供，该文件不进入 Git。
